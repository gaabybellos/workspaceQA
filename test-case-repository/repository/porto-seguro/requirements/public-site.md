# Public Site Requirements

## REQ-PORTO-SMOKE-001 - Public Home Availability

The public home page must load visible navigation, logo, and public product or service content.

Source: `docs/technical/porto-seguro/modules/home/README.md`.

## REQ-PORTO-SMOKE-002 - Public Navigation Visibility

The public header must expose navigation entries and the Area do Cliente link without requiring authentication for visibility.

Source: `docs/technical/porto-seguro/routes.md`.

## REQ-PORTO-CUPOM-001 - Public Coupon Visibility

Public promotional coupons must be visible with a copy action when the campaign is displayed.

Source: `docs/technical/porto-seguro/modules/home/README.md`.

## REQ-PORTO-SERV-001 - Public Services Listing

The services page must show service categories, service cards, and informational content without requiring login.

Source: `docs/technical/porto-seguro/modules/servicos/README.md`.

## REQ-PORTO-SERV-002 - Services FAQ

The services page must expose FAQ content to answer public user questions.

Source: `docs/technical/porto-seguro/modules/servicos/README.md`.

## REQ-PORTO-VIAG-001 - Seguro Viagem Public Entry

Seguro Viagem must expose a public entry point to start or learn about quote options.

Source: `docs/technical/porto-seguro/modules/seguro-viagem/README.md`.

## REQ-PORTO-API-001 - Controlled Network Behavior

The automation suite must validate controlled network behavior without calling private APIs directly.

Source: `docs/technical/porto-seguro/test-architecture-plan.md`.
