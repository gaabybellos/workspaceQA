# Numbering Policy

## Format

```text
TC-<PROJECT>-<DOMAIN>-<NUMBER>
```

## Rules

- `PROJECT` is the uppercase project slug with up to 6 characters.
- `DOMAIN` is the uppercase functional domain.
- `NUMBER` is a three-digit sequence.
- Do not reuse retired IDs.
- Record allocated IDs in `test-case-repository/repository/<slug>/numbering.md`.

## Example

```text
TC-SHOP-CATALOG-001
```
